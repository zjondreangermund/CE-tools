# Implementation status

- Preserved command reconciliation: the active source restores the verified V54/V60 command surface while retaining newer commands and implementations, and now contains 397 unique AutoCAD commands. Missing Civil 3D support sources, six host-independent engineering cores and the 33-record engineering asset catalogue are restored. The short-path build recovery step now acts only as a missing-file fallback and cannot overwrite reconciled active source. Civil 3D 2023 compile and the restored-command runtime plan remain mandatory release gates.

- `CE_BMVERT`: alpha source complete; live Civil 3D validation in progress.
- `CE_TLENGTH`: alpha source complete; Civil 3D validation required.
- `CE_TAREA`: alpha source complete; Civil 3D validation required.
- `CE_COORDINATE`: installed alpha works; redesign pending the user's reference coordinate LSP.
- `CE_COORDPOLY`: polyline-direction vertex extraction, sequential Civil 3D COGO-point creation, sequential raw descriptions and XYZ table generation are source-complete; Civil 3D 2023 compile, old/new polyline, point-number and table validation required.
- `CE_SEWSEQ`: extended without a duplicate command; default `EntireNetwork` mode expands selected parts to complete networks, decomposes tree-shaped networks into highest-to-lowest branches, orders remaining branches longest-to-shortest, and applies dotted `MHn.x` / `Pn.x` names. Existing `SelectedPath` mode remains available. Civil 3D 2023 compile and live topology validation required.
- `CE_SEWALIGN`: creates or refreshes one siteless Civil 3D alignment per CE-sequenced sewer branch, follows straight and sampled curved pipe geometry from high rim to low rim, places a visible `Branch-n` plan label and replaces only CE-generated alignment/label objects on rerun. Civil 3D 2023 compile, style, XData, naming-conflict and refresh validation required.
- `CE_COLOR250` / `COLOR250`: alpha source complete; Civil 3D validation required.
- `CE_PLDIR`: ordinary 2D/3D polyline direction arrows with linked replacement and selected/all clearing are source-complete; AutoCAD/Civil 3D 2023 compile, curve direction, XData and locked-layer validation required.
- `CE_HATCHTOOLS`: first hatch batch is source-complete with transparent associative `Create`, batch `Edit`, visual-setting `Match` and draw-order `Back`. Hatches use user-entered predefined pattern, scale, angle, ACI colour and 0-90 percent transparency, are placed on `CE-HATCH` and sent behind linework. AutoCAD/Civil 3D 2023 compile, pattern-library, associativity, planar-boundary, transparency-display/plot and draw-order validation required.
- `CE_FLTOOLS`: first alpha source complete with `Report`, `RaiseLower` and `SetElevation`; Civil 3D 2023 compile and feature-line validation required.
- `CE_FLEDIT`: second feature-line alpha batch complete with `Create`, `Surface`, `Insert` and `Delete`; Civil 3D 2023 compile and drawing validation required.
- `CE_FLWEED`: conservative elevation-point weeding with preview, vertical tolerance and spacing tolerance is source-complete; Civil 3D 2023 compile and drawing validation required.
- `CE_FLREL`: linked stepped-offset feature-line workflow is source-complete with `Create`, `Update`, `Info` and confirmed `Detach`. Children store their source handle and cumulative horizontal/vertical relationship inside the DWG; update rebuilds every linked child while preserving name, layer, style and site. Civil 3D 2023 compile, curved offset, elevation-point, site, naming and update validation required.
- `CE_ALTOOLS`: first alignment alpha batch complete with `Report`, `StationOffset` and `Label`; Civil 3D 2023 compile, station-equation and left/right validation required.
- `CE_PRTOOLS`: first profile alpha batch complete with `Report`, `Elevation` and plan `Label`; Civil 3D 2023 compile, profile-selection, station-equation and label validation required.
- `CE_SFTOOLS`: first surface alpha batch complete with `Report`, `Elevation`, `Label` and point `Compare`; Civil 3D 2023 compile, boundary, UCS and cut/fill-sign validation required.
- `CE_CORTOOLS`: first corridor alpha batch complete with `Report`, detailed `Baselines`/regions and controlled `Rebuild`; Civil 3D 2023 compile, source-resolution, reference and rebuild-transaction validation required.
- `CE_PKTOOLS`: first parking alpha batch complete with straight `Row`, aisle-centred `DoubleRow`, bay `Count` and sequential `Number`; Civil 3D 2023 compile, geometry-direction, layer, count and numbering validation required.
- `CE_WSCOSTTOOLS`: linked water/sewer Excel cost-estimate creation, explicit refresh, information and deferred automatic refresh are source-complete. The automatic manager queues database changes and updates the workbook only after the drawing command ends; it is registered through the plugin lifecycle and exposed on the Analysis ribbon. Civil 3D 2023 compile plus Excel Move/Stretch/Erase/Undo, drawing-switch and drawing-close validation are required.
- `CE_REFRESHALL` / `CE_REFRESHSTATUS` / `CE_AUTOREFRESH`: shared, fault-isolated refresh and status reporting are source-complete for linked coordinate tables, setting-out schedules, parking labels, surface comparisons, BOQs, water/sewer cost workbooks and dynamic cross sections. Coordinate, setting-out and BOQ tables now use a per-drawing deferred automatic-refresh setting (default On); database events only queue work and rebuilding occurs after the command ends. Issue books and project summaries remain separate confirmation workflows. Civil 3D 2023 compile, stale-link isolation, repeated refresh, deferred update, Undo and save/reopen validation are required.
- `CE_PROJECT`: first project metadata alpha batch complete with `Setup`, `Info` and confirmed `Clear`; Civil 3D 2023 compile, Named Objects Dictionary, save/reopen and Save As validation required.
- `CE_COORDSYS`: first coordinate-system alpha batch complete with `Info`, validated `Assign`, library `Search` and confirmed `Clear`; Civil 3D 2023 compile, Autodesk code-library, persistence and geometry-nontransformation validation required.
- `CE_STANDARDS`: first standards-selection alpha batch complete with `Select`, `Info`, confirmed `Clear` and CE Project metadata synchronisation; Civil 3D 2023 compile, persistence, cancellation and metadata-sync validation required.
- `CE_DESIGNSTANDARDS`: searchable Southern African design-standards reference library is source-complete with category `Browse`, multi-term `Search`, confirmed `Apply` as primary/additional and current-project reporting. It reuses the existing `STANDARDS_SELECTION` DWG record and project metadata instead of creating a duplicate standards store. Catalogue entries include Namibia authority requirements, COTO, key TRH families, TMH, SAPEM, SARTSM, the CSIR Red Book, applicable SANS and project-specific specifications. Civil 3D 2023 compile, metadata compatibility, search, persistence and catalogue-review validation required.
- Ribbon architecture: the installed-command set is source-complete in Project, Survey, Drawings, Geometry, Site Design, Utilities, Standards and Analysis category panels with compact three-row AutoCAD-style drop-down module buttons. The Drawings panel now includes Drawing Tools, Drawing Cleanup and Hatch Tools as three neat rows. The CE Tools tab is rebuilt from the current definition on startup to remove legacy panels and prevent duplicate ribbon commands. Civil 3D 2023 compile and visual ribbon validation are required. Remaining future categories will be added only when their first real commands exist.
- Workflow command centre: the automatic Ctrl+F window now merges ribbon metadata with every `CommandMethod` declared by the loaded CE Tools assembly, de-duplicates by global command name and exposes an explicit All tab before the General, Survey, Roads, Stormwater, Sewer, Water, Bulk Water and Flood workflows. The command-catalogue module adds a complete report, runtime audit, UTF-8 CSV export, searchable offline HTML reference and ribbon/catalogue refresh. This makes all 397 commands searchable and launchable even when a specialist command is not pinned to the ribbon. Civil 3D 2023 startup, reflection, search, launch, export and multi-monitor validation are required.
- User-comment reconciliation: the active acceptance comments are now tracked in `docs/USER_COMMENT_TRACEABILITY.md` and protected by `Validate-UserCommentCoverage.py`. The audit corrected the survey table to `POINT NAME, X, Y, Z`, added multi-polyline vertex selection, implemented real dynamic coordinate/annotation movement and surface-Z refresh, restored `CountLinks`, and replaced destructive bundle installation with staged SHA-256 verification plus automatic rollback and a source-commit install log. Items that still require Civil 3D runtime validation or future development are explicitly separated from source-complete work.
- Settings centre: `CE_SETTINGS` and `CE_SETTINGSCENTER` now present 21 configuration entry points in one searchable, discipline-filtered WPF window. `CE_SETTINGSAUDIT` reports coverage. This removes command-line keyword selection for the settings launcher while retaining drawing-based Civil 3D object selection inside specialist commands. Remaining numeric specialist prompts will continue moving into focused dialogs as those modules are polished.
- Discipline production dialogs: `CE_SWTOOLS`, `CE_SEWTOOLS` and `CE_WATERTOOLS` now open ordered WPF workflow windows instead of keyword menus. Their settings windows enumerate installed Civil 3D alignment/profile/profile-view/label-set/band-set styles, offer standard 1.8/2.0/2.5/3.5/5.0 paper heights, persist profile-view rows/columns spacing and retain water asset-spacing rules. Stormwater and Water profile surface selection now uses the same readable surface catalogue already used by Sewer. Destructive confirmations are modal windows; only geometry-dependent canvas picks remain native prompts.
- V61 release pipeline: assembly and bundle versions are synchronized at 0.61.0, both Civil 3D 2023 build paths emit the same versioned package, and the package includes a double-click elevated installer, source-commit release manifest and checksum register. Source, staged and installed bundles are hash-verified with automatic rollback. `CE_VERSION`, `CE_INSTALLVERIFY` and `CE_UPDATECHECK` expose the exact installed state. A self-hosted Windows/Civil3D2023 GitHub workflow is ready but requires a configured runner with Autodesk Civil 3D 2023.
