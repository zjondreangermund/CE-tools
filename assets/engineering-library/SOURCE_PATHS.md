# Controlled source paths

The catalog uses these relative roots:

- `Source/PDF/General`
- `Source/PDF/Roads`
- `Source/PDF/Stormwater`
- `Source/PDF/Sewer`
- `Source/PDF/Water`
- `Source/XLSX/Roads`
- `Source/XLSX/Sewer`
- `Source/XLSX/Water`

All uploaded records are initially `ForReview`. PDF and XLSX records are searchable and auditable. Controlled drawing insertion remains limited to reviewed DWG assets.
