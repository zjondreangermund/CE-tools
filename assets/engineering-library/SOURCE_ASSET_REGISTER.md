# Uploaded Phase 8 Source Asset Register

The source pack contains road, stormwater, sewer and water drawing sheets plus setting-out and quantity workbooks uploaded on 26 July 2026.

All records are initially classified as `ForReview`. The uploaded files are not treated as engineer-approved merely because they are present in the library.

The generated `engineering-assets.csv` stores SHA-256 values calculated from the original uploaded bytes. Binary source files are retained outside the source-code normalisation workflow and must remain read-only.
